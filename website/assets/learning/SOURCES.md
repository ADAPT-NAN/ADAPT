# Nan learning map

Center data and simplified district/subdistrict GeoJSON were retrieved on 2026-10-04 from the user-supplied Nan Learning Centers website:

- https://dpongchai.github.io/nan-learning-centers/
- https://dpongchai.github.io/nan-learning-centers/data/centers.json
- https://dpongchai.github.io/nan-learning-centers/data/nan-boundaries.json

The local snapshot contains 30 centers, 15 districts, and 99 subdistricts. Names, translations, coordinates, course status, descriptions, and optional contact fields are preserved from the source. These are simplified reference boundaries, not survey data. Updates to the source do not automatically change this snapshot.
